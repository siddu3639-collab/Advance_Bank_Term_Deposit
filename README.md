# Advance Bank Term Deposit Subscription Prediction

## 📌 Project Overview
This project predicts whether a customer will subscribe to a bank term deposit using Machine Learning. The objective is to analyze customer behavior, identify the factors influencing subscription decisions, and build a predictive model that can assist banks in improving their marketing campaigns.

---

## 📂 Dataset
- **Dataset:** Bank Marketing Dataset
- **Records:** 41,188
- **Features:** 21
- **Target Variable:** Term Deposit Subscription (Yes/No)
